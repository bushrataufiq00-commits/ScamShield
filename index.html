    // HOW SCAMSHIELD WORKS
    A simple explanation you can use during your project presentation.
    01 // INPUT

    The user provides a suspicious message or URL for analysis.

    02 // RULE ENGINE

    ScamShield checks for patterns such as urgency, account threats, OTP requests, payments, suspicious URLs and other indicators.

    03 // RISK SCORE

    Detected indicators contribute to a score from 0 to 100 and produce Safe, Suspicious or Likely Scam.

    04 // AI ASSISTANCE

    For uncertain message results, the backend can request a short Gemini-based explanation.

    // SAFETY PROTOCOLS
    General precautions for suspicious messages and links.
    NEVER SHARE OTPs

    Do not share OTPs, passwords, PINs or card security information with unexpected contacts.

    VERIFY THE SOURCE

    Contact the organization through its official website or known contact method instead of using a suspicious message.

    CHECK THE URL

    Look for HTTPS, unusual domains, excessive subdomains, IP addresses and unexpected URL structures.

    DON'T PANIC

    Scammers often create urgency. Take time to verify a request before clicking, paying or responding.

    ScamShield is an educational risk-assessment tool. A Safe result does not guarantee that content is legitimate, and a suspicious result is not proof of fraud.
